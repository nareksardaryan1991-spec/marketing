# Marketing — заметки для работы над проектом

Приложение агентства: клиенты заказывают продвижение, команда делает материалы.
Полное описание, решения заказчика и план — в `README.md` (раздел «Состояние проекта»).
Заказчик общается по-русски.

## Устройство
- `apps/mobile/` — Expo SDK 57 + Expo Router, iOS/Android/веб из одного кода.
  Правила Expo — в `apps/mobile/AGENTS.md` (сверяться с документацией нужной версии SDK).
- `supabase/migrations/` — схема и права доступа (RLS). Правила ролей живут в функциях базы
  (`is_team_role`, `is_employee_role`, `is_manager`, `is_admin`); в приложении их зеркалит
  `apps/mobile/src/lib/roles.ts` — менять вместе.
- `supabase/functions/` — Edge Functions (Deno): оплата, AI (Claude), уведомления, Instagram.
- `scripts/` — `setup.sh` (облако), `local.sh` (Docker локально), `preview.sh` (просмотр без Docker),
  `make-admin.sh` (назначить владельца).

## Проверки перед тем, как сказать «готово»
```bash
cd supabase/tests && npm test && npm run test:seed        # база и демо-данные (PGlite)
cd supabase/functions && npx --yes deno@2 check */index.ts
cd apps/mobile && npx tsc --noEmit && npx expo lint
cd scripts/preview && PREVIEW_URL=<тестовый сервер> npm run e2e   # сквозной тест в Chrome
```
Новые правила в базе — сразу покрывать проверками в `supabase/tests/db.test.mjs`.

## Грабли, на которые уже наступали
- **Кэш Metro запоминает `EXPO_PUBLIC_*`.** При сборке с другим адресом сервера всегда
  `npx expo export ... --clear`, иначе в сборку попадёт старый адрес.
- **Просмотровый сервер на :8081 — это данные заказчика.** Он хранит всё в памяти;
  перезапуск, `preview.sh` (перезапускает сервер) и `/__reset` стирают то, что заказчик
  там сделал. Без предупреждения не сбрасывать. Чтобы обновить только приложение, пересобрать
  `dist-preview` без перезапуска сервера. Сквозной тест гонять на отдельном сервере/порту
  со сборкой под этот порт (тест сам остановится, если сборка смотрит на другой сервер).
- Новое значение enum в Postgres нельзя использовать в той же миграции — отдельный файл.
- Node: нужен 20 из nvm (`source ~/.nvm/nvm.sh`), системный `/usr/bin/node` — v12.
- Docker на машине пока не установлен (нужен sudo заказчика) — полноценный локальный
  запуск ждёт этого.
